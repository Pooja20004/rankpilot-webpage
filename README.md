RankPilot is an intelligent preparation and test diagnostic platform for **JEE Main & JEE Advanced** aspirants. It replaces blind mock testing and generic batch schedules with real-time AI error taxonomy, zero-to-hero coaching sprints, 24/7 instant doubt resolution, and authentic NTA shift simulations.

## 🌟 Key Features

1. **In-Depth Front Page & About Section**
   - Detailed breakdown of RankPilot's AI diagnostic architecture.
   - Interactive *Traditional Coaching vs RankPilot AI* comparative table.
   - Comprehensive Exam Coverage matrix for JEE Main (140+ shifts), JEE Advanced, BITSAT, and State CETs.

2. **Interactive 7-Feature Tabs Hub**
   - 📝 **JEE Main & Advanced PYQ Mocks**: Authentic NTA shift selector with an interactive **3-Question Mini Mock Drill** featuring a live countdown timer, answer selection, and instant AIR/Percentile calculation.
   - 📊 **Deep Analytics ("Performance, Decoded.")**: Subject mastery vs AIR 100 toppers radar, 3-layer error taxonomy (Silly 42%, Conceptual 38%, Panic 20%), and actionable marks-leak prescription.
   - 🤖 **Personal AI Coach ("Zero-to-Hero")**: Target percentile slider (85.0 to 99.9%ile) generating dynamic daily high-weightage sprint checklists.
   - 📅 **Dynamic Study Planner**: Customizer for daily hours and weak topics with instant AI timetable generation.
   - 💡 **24/7 AI Doubt Solver**: Live interactive simulator with step-by-step LaTeX proofs, governing formula highlights, common pitfalls, and related shift PYQs.
   - 📈 **My Reports**: Granular question-level diagnostic table with speed vs topper benchmarking.
   - 👥 **Registered Students & Cohorts**: National leaderboard and cohort tracking.

3. **Interactive AI Video Feature Explainer**
   - Guided audio-visual walkthrough player with chapter navigation for every feature.
   - **Voice Narration** powered by Web Speech API with Play, Pause, Speed (1x, 1.25x, 1.5x), and Mute controls.
   - Dynamic sound wave visualizer and synchronized subtitles.

4. **Interactive Reviews & Rating Hub**
   - 4.92/5 rating summary with 5-star distribution.
   - Feature-level tab filtering.
   - **"Write a Tab Review" Modal** with star ratings, feature tags, local storage persistence, and confetti animation.
   - Interactive upvote / helpful counters on all reviews.

5. **Live Marks vs Percentile & AIR Predictor**
   - Interactive score slider (20–300 marks) forecasting percentile, All India Rank, and eligible NIT/IIIT/IIT branch allocations.

6. **Direct Launch & VIP Signup Portal**
   - Fast registration form generating a personalized VIP Aspirant Pass linking directly to the Lovable App project.

## 🛠️ Quick Setup & Run Locally

```bash
# Clone the repository
git clone https://github.com/Pooja20004/rankpilot.git

# Navigate to project directory
cd rankpilot

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 📦 Build for Production

```bash
npm run build
```
The production bundle will be generated in the `dist` directory.
